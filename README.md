# JavaJam Coffee House

A website for a coffee shop built with Python, Flask, and SQLite.

## Features
- Home page and job listings page
- Navigation menu shared across all pages
- Admin dashboard (Flask-Admin) to add, edit, and delete jobs

## How to run
1. Install requirements: `pip3 install -r requirements.txt`
2. Run the app: `python3 application.py`
3. Open `http://127.0.0.1:5000` in your browser

## Admin
Open `/admin` to manage job postings.
